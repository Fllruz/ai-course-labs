## 1. Цель работы

Агент должен уметь использовать различные инструменты (поиск, вычисления, специализированные функции), сохранять контекст диалога в рабочей и семантической памяти, а также фильтровать небезопасные запросы через guardrails. Полученные навыки применяются для создания интеллектуальной системы управления PTZ-камерой в рамках дипломной работы.

## 3. Ход работы
### 3.1. Архитектура агента
Агент реализован на базе фреймворка LangChain с использованием паттерна ReAct (Reasoning + Acting). Архитектура включает следующие компоненты:

**Основные модули:**

1. **LLM (YandexGPT)** – языковая модель для обработки запросов и принятия решений
2. **Инструменты (Tools)** – набор функций для выполнения конкретных задач:
   - `SearchTool` – поиск информации в интернете
   - `CalculateTool` – выполнение математических вычислений
   - `CustomTool` – управление PTZ-камерой (слежение за объектами)
3. **Память (Memory)** – двухуровневая система хранения:
   - `WorkingMemory` – краткосрочная память для хранения истории диалога
   - `SemanticMemory` – долгосрочная память на базе ChromaDB для семантического поиска
4. **Guardrails** – система безопасности для фильтрации вредоносных запросов
5. **AgentExecutor** – исполнитель, управляющий циклом "мысль → действие → наблюдение"

**Схема взаимодействия:**
Пользователь → Guardrails → AgentExecutor → LLM (ReAct) → Tools → Memory → Ответ
↓
SemanticMemory (ChromaDB)

### 3.3. Кастомный инструмент

**Назначение:** Интеллектуальное управление PTZ-камерой с функцией автоматического слежения за движущимися объектами.

**Алгоритм работы:**

1. Парсинг координат объекта из строки bounding_box
2. Валидация координат в пределах кадра
3. Фильтрация по уровню уверенности (confidence < 0.6 → предупреждение)
4. Расчёт центра объекта и отклонения от центра кадра
5. Вычисление углов панорамирования (Pan) и наклона (Tilt) с помощью P-регулятора
6. Расчёт коэффициента зума на основе относительного размера объекта
7. Применение фильтра Калмана для сглаживания траектории
8. Формирование JSON-ответа с командами для камеры

**Листинг кода (основная логика):**

### 3.5. Интеграция с дипломом
Материалы лабораторной работы будут использованы в дипломном проекте "Интеллектуальная система управления видеокамерой с функцией слежения за объектами" следующим образом:

Кастомный инструмент – станет ядром системы слежения, отвечающим за расчёт углов поворота камеры и коэффициента зума на основе данных детекции объектов.

Агентная архитектура – позволит расширить систему для голосового управления камерой, где пользователь сможет отдавать команды естественным языком.

Семантическая память – будет использоваться для хранения информации о типичных сценариях слежения, чтобы система могла адаптироваться под конкретные условия (освещение, тип объектов, фон).

Guardrails – обеспечат безопасность системы, предотвращая выполнение недопустимых команд (например, направление камеры в запрещённые зоны).

Инструменты поиска и калькулятор – позволят агенту находить справочную информацию о новых алгоритмах детекции и выполнять необходимые математические расчёты в реальном времени.

Трудности и их решение:

Проблема: Ошибка мульти-инструментов в LangChain (ZeroShotAgent does not support multi-input tool)
Решение: Переход с initialize_agent на create_react_agent с явным определением промпта

Проблема: Ограничения Pydantic при добавлении атрибутов в CustomTool
Решение: Использование глобального словаря _TRACKING_STATE для хранения состояния

Проблема: Отсутствие модулей WorkingMemory и InputGuardrails
Решение: Создание упрощённых аналогов (SimpleWorkingMemory, SimpleGuardrails)

Планы по развитию:
